# 10 — Exercice de crise ransomware

## Finalité

Démontrer le traitement d’un incident majeur comme un cycle complet, depuis la détection jusqu’au retour d’expérience.

## Parcours de lecture

1. [`Chronologie_Incident.md`](Chronologie_Incident.md) — déroulé de l’incident ;
2. [`Cellule_De_Crise.md`](Cellule_De_Crise.md) — gouvernance et rôles ;
3. [`Procedure_Ransomware.md`](Procedure_Ransomware.md) — actions opérationnelles ;
4. [`Rapport_Incident.md`](Rapport_Incident.md) — formalisation des faits et impacts ;
5. [`Retour_Experience.md`](Retour_Experience.md) — causes, enseignements et actions correctives.

## Ce que ce dossier démontre

- coordination technique / métier / direction ;
- distinction confinement, reprise et communication ;
- transformation du RETEX en actions d’amélioration.

Le scénario est entièrement fictif.
