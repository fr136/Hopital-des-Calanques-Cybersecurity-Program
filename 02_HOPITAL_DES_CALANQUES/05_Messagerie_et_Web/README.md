## Logique de défense

Les contrôles combinent règles d’usage, filtrage, sensibilisation et capacité de détection. Un contrôle utilisateur seul n’est pas considéré comme suffisant.

## Limite

Ces documents décrivent une politique cible fictive. Le laboratoire RésiSanté ne reproduit pas une infrastructure complète de messagerie hospitalière.
