# 02 — Gestion des risques

Identifier les actifs importants, qualifier les scénarios de risque, prioriser les traitements et conserver une trace des décisions.

## Positionnement méthodologique

Le document EBIOS est un exercice simplifié : il ne constitue pas une étude EBIOS Risk Manager complète. Le laboratoire RésiSanté dispose séparément de sa propre analyse qualitative vraisemblance × impact.

## Ce que ce dossier démontre

- passage de l’actif au scénario puis au traitement ;
- priorisation en fonction du risque ;
- lien entre risque, propriétaire, action, échéance et preuve.
