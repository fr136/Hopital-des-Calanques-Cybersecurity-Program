# 01 — Gouvernance cybersécurité

## Finalité

Définir qui décide, qui met en œuvre, qui contrôle et quelles règles communes structurent la sécurité du SI fictif.

## Livrables

- [`Politique_Cybersecurite.md`](Politique_Cybersecurite.md) — principes directeurs ;
- [`Organisation_RSSI.md`](Organisation_RSSI.md) — rôles et responsabilités ;
- [`Comite_Cyber.md`](Comite_Cyber.md) — instance de pilotage ;
- [`Charte_Utilisateur.md`](Charte_Utilisateur.md) — règles applicables aux utilisateurs.

## Articulation

La gouvernance fixe le cadre dans lequel sont traités les risques, les habilitations, la continuité, les incidents et l’amélioration continue. Les paramètres présentés restent fictifs et doivent être adaptés dans une organisation réelle.

## Ce que ce dossier démontre

- formalisation d’une gouvernance SSI ;
- distinction Direction / DSI / RSSI / DPO / métiers ;
- traduction des objectifs de sécurité en règles compréhensibles.
