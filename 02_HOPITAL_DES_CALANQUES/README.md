# Hôpital des Calanques — cadre métier et programme GRC

L’Hôpital des Calanques est un **établissement entièrement fictif** utilisé comme contexte métier pour structurer un programme cybersécurité cohérent dans le secteur santé.

Cette partie du dépôt ne prétend pas reproduire un SI hospitalier réel ni démontrer une mission RSSI effectivement réalisée. Elle sert de **cadre de gouvernance, de risques, de continuité et de conformité** autour du projet principal RésiSanté.

## Rôle dans le projet

RésiSanté constitue la mise en œuvre technique et opérationnelle d’un périmètre représentatif. L’Hôpital des Calanques fournit le contexte dans lequel les choix techniques prennent leur sens : activités critiques, responsabilités, risques, continuité, crise, sensibilisation et exigences de gouvernance.
